# Локальный вайб

Версия 1.1.0. Пульт интенсивности для взрослой сцены по согласию: уровень 0–20, рисунок, потолок, автостоп и стоп-слово. Вибрация — у этого устройства. Сокет — только localhost, имя `.local` или частная сеть.

Чужие аккаунты игрушек и публичные вебхуки не вызываются. Кнопка обновления в Таверне — это её `git pull` этого репозитория.

## Установка в SillyTavern

Кнопка обновления есть только у установки из git.

1. «Расширения» → «Установить расширение».
2. Адрес: `https://github.com/Prohor-godslayer/local-vibe`. Ветка `main`.
3. В «Управление расширениями» карточка «Локальный вайб», версия 1.1.0.
4. Включи «Уведомлять об обновлениях расширений», если пункт есть.

Кнопка ≋ у края чата. Пункт меню — «Локальный вайб».

Папку без git в `data/<пользователь>/extensions/local-vibe` удали и поставь по ссылке.

### Когда Таверна говорит, что нужно обновить

`"version": "1.1.0"` и `"auto_update": true`. Сравнение с `origin/main`. Кнопка по-английски — **Update available**, по-русски — перевод из языкового пакета. Нажатие делает `git pull`.

## Установка в Tavo

1. Скачай `tavo/local-vibe.tpg`: https://github.com/Prohor-godslayer/local-vibe/blob/main/tavo/local-vibe.tpg
2. Импортируй плагин. Сетевого права нет. Нужны сообщения, переменные и файл. Сокет к домашнему адресу открывает сам браузер, отдельного права «сеть» в манифесте нет.
3. Открытие: кнопка ≋, действие ввода «Локальный вайб», боковая панель.

Новую версию ставь повторным импортом `.tpg`. Версия плагина 1.1.0.

## Как пользоваться

1. Ползунок задаёт уровень руками. Пока тянешь, полоска и цифра обновляются сразу. Ноль останавливает отдачу, сам пуск при уровне выше нуля включается.
2. Рисунок: волна, пульс, сердце, нарастание, прибой, ровно, кромка, тишина. Рисунок умножает уровень, а не заменяет его. «Тишина» даёт ноль даже при высоком уровне.
3. «Пуск» и «Стоп» включают и гасят отдачу. «Стоп сразу» гасит и обнуляет уровень.
4. «Потолок и слово».
   - «Слушать ответы персонажа» — уровень двигается по тексту ответа. Без галочки сцена уровень не трогает, стоп-слово в твоём сообщении всё равно работает.
   - «Вибрация этого телефона» — `navigator.vibrate`, если устройство это умеет.
   - «Намёк персонажу» — в промпт уходит одна строка про ощущение, без марок и без интерфейса. Только пока пульт запущен.
   - Потолок режет уровень. Автостоп гасит пульт через 5, 10, 20, 45 минут или не гасит, если выбран «без автостопа».
   - Стоп-слово ищется как отдельное слово в твоём сообщении. «стоп» не срабатывает внутри «стопка». После слова пульт запирается. «Снять замок» снова пускает ползунок.
5. «Устройство». Адрес по умолчанию `ws://127.0.0.1:12345` — обычный Intiface на этом компьютере. Подходят также `localhost`, `::1`, `10.*`, `192.168.*`, `172.16–31.*` и имена `*.local`, по `ws`, `wss`, `http` или `https`. Любой другой адрес панель не сохранит. «Короткий тест» на долю секунды даёт уровень 6 и возвращает то, что было.
6. Смена чата останавливает пульт и гасит устройство. Замок при этом не ставится.

Без локального Intiface остаются экран и вибрация телефона. Этого достаточно, чтобы видеть уровень.

## Где лежат данные

Настройки общие для клиента, не на чат. SillyTavern: `settings.json`, ключ `local_suite_vibe`. Tavo: `lx_vibe_cfg`.
