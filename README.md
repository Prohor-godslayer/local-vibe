# Локальный вайб

Пульт интенсивности по тексту сцены: уровень, рисунок, потолок, автостоп и стоп-слово. Вибрация идёт через это устройство. Сокет принимается только для localhost, имени `.local` или частной сети. Адрес по умолчанию: `ws://127.0.0.1:12345`.

Облачные аккаунты игрушек и публичные вебхуки отсутствуют. По желанию в промпт добавляется короткая пометка ощущения силами самого клиента.

## SillyTavern

Скопируйте репозиторий в `data/<пользователь>/extensions/local-vibe`. Панель: кнопка у края чата и пункт «Локальный вайб».

## Tavo

Импортируйте `tavo/local-vibe.tpg`.
